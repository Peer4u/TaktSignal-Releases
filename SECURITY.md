# Security

**Report suspected vulnerabilities privately by e-mail to work.manhcang@gmail.com** (subject: "Security"). Do not
open a public issue, discussion or post for a suspected vulnerability.

Please include the TaktSignal version (Control Center, top right), your operating system, what the problem is and
how to reproduce it — ideally with synthetic data or a test ERPNext site.

**Never send** real factory data, ERPNext or TaktSignal backups, database dumps, API keys, passwords or tokens.

We aim to acknowledge reports within 5 working days (the project is small) and follow coordinated disclosure
(normally up to 90 days). Only the latest Community Alpha release receives fixes. There is no bug bounty.

Full policy: https://taktsignal.cloud/security
